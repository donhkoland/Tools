# Less handoff. More flow.

Pick the point where your process gets repetitive. These tools can work together, but none depends on the others.

## From a web layout to editable layers

Open your own page or a reference you have permission to process in [HTML to Layers](https://github.com/donhkoland/html-to-layers). Analyze it, review the warnings, and export a PSD for Photoshop or an SVG for Figma.

Use the result as a starting point for editing. Check fonts, clipping, effects, and layer order before continuing. The aim is to save reconstruction time, not promise a perfect round trip.

## From a design to a web sketch

Bring in a layered PSD, or export an SVG from Figma with **Outline text** turned off. Switch HTML to Layers to its reverse mode, review the preview and font mapping, then save the HTML and images.

Use it to try a composition or share a visual direction. Semantics, responsive behavior, accessibility, and application logic still need deliberate work.

## From browsing to a local reference

Open [Site Mirror](https://github.com/donhkoland/site-mirror) from the page you want to save. Pick a folder, set limits, and grant access to the sites it needs. Review the report for missing resources. If you stop midway, reopen the same folder and resume.

It collects and checks a static copy. It doesn't copy a site's backend or guarantee that an infinite gallery has been fully explored.

## From scattered drives to a searchable archive

Register a drive or folder in [Disk Atlas](https://github.com/donhkoland/disk-atlas), let it scan, and review any warnings. You can then search names, projects, and formats while the drive is unplugged. Reconnect the original to open a file.

The catalog remembers where things are. It isn't a backup of the files themselves.

## From finished creative to a campaign you can review

Set up your own app and account in [Meta Ads Manager](https://github.com/donhkoland/meta-ads-manager). Choose a post, account, and budget. Save a paused campaign first, then check it in Meta Ads Manager before activating it.

This integration is experimental. Real access depends on Meta's permissions and requirements. Activating ads can spend real money.
