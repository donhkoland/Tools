Built around real design, production, and archiving tasks. Open to use, study, and adapt. Each tool cuts down a handoff and is upfront about its limits.

## HTML to Layers

**Take a layout somewhere new.**

Turn a web page into a layered PSD for Photoshop or an SVG for Figma. Go the other way, too: bring a PSD or SVG back into an HTML sketch with real text and images.

Good for exploring compositions, recovering an editable starting point, and moving a visual direction between tools. Fonts and effects need a check. It doesn't turn a design into a production-ready website.

Includes the browser tool, a local Python helper, a made-up example, and a guide. Chrome or Edge recommended.

Source and downloads: https://github.com/donhkoland/html-to-layers

## Site Mirror

**Keep a reference close.**

Save a website or gallery as a static local copy. Look for original image files, pause a download, and pick up later with checks on what's already saved.

Includes a Chrome extension to load manually and a guide. Saved sites, login sessions, and third-party content aren't included. It doesn't copy databases or server code.

Source and downloads: https://github.com/donhkoland/site-mirror

## Disk Atlas

**Know where it is. Even when the drive isn't here.**

Catalog drives and folders, then search their contents while they're unplugged. Find the right project before deciding what to reconnect.

Includes a local Python app, web interface, and setup guide. Built with Windows in mind. The catalog is a map, not a backup.

Source and downloads: https://github.com/donhkoland/disk-atlas

## Meta Ads Manager · experimental

**From an existing post to a campaign you can review.**

Choose content and prepare campaign settings in one place. You'll need your own Meta developer app, permissions, and ad account. Tests use mocked responses; real access must be checked with your own account.

Includes Node.js source, the interface, a sample configuration, and setup notes. No credentials or account access included. This isn't a hosted service or an integration endorsed by Meta.

Source and downloads: https://github.com/donhkoland/meta-ads-manager
