# Tools

**Small tools. Fewer steps. More room to make things.**

An open collection by [@donhkoland](https://github.com/donhkoland).

These tools grew out of the gaps in a creative workflow: moving a web layout into editable layers, getting a design back into HTML, saving a reference, or finding a file on a drive that isn't plugged in.

They started as practical experiments, shaped through AI-assisted coding and hands-on iteration. Each one tackles a specific handoff so you can get back to the work. The source, setup notes, and known limits are here for anyone who wants to use them or take them further.

## Pick your next step

| Tool | What it does | Where it fits |
| --- | --- | --- |
| [HTML to Layers](https://github.com/donhkoland/html-to-layers) | HTML/URL → PSD or SVG; PSD/SVG → HTML | Move a layout between the browser, Photoshop, and Figma |
| [Site Mirror](https://github.com/donhkoland/site-mirror) | Website or gallery → local folder | Save references and original images; pause and resume verified downloads |
| [Disk Atlas](https://github.com/donhkoland/disk-atlas) | Drives and folders → searchable local catalog | Find material even when the original drive is offline |
| [Meta Ads Manager](https://github.com/donhkoland/meta-ads-manager) | Existing posts + settings → campaign | Prepare a campaign in one place; experimental, with your own Meta app and permissions |

Each tool has its own repository, setup guide, issues, and downloads. This repo is the collection's front door.

## Made to fit into your workflow

**Explore → save → reshape → organize → share.**

You might save a reference with Site Mirror, bring the layout into HTML to Layers, then catalog the working files with Disk Atlas. Meta Ads Manager comes later, when the creative and the offer are ready. Use the steps that help; skip the rest.

## Open source, personal data kept out

The published projects contain source code and made-up examples. Private catalogs, device paths, credentials, sessions, client files, and downloaded websites stay out of the repositories and release packages.

The tools create their own working data on the user's computer. Network access is described in each project's README. There's no Tools account, activation service, or added analytics.
